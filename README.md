
# FitLife — Site de saúde e treinos

## Como abrir

1. Extraia a pasta FitLife-site.
2. Abra a pasta no Visual Studio Code.
3. Instale a extensão Live Server.
4. Clique com o botão direito em index.html.
5. Selecione Open with Live Server.

## Funcionalidades

- Painel com resumo do dia.
- Registro de treinos em horas e minutos.
- Estimativa aproximada de calorias.
- Controle de água.
- Metas personalizadas.
- Histórico de treinos e hidratação.
- Layout responsivo para computador e celular.

## Armazenamento

Os dados são salvos no localStorage do navegador.
Isso significa que ficam neste navegador e neste dispositivo.
Esta versão não tem login nem sincronização entre dispositivos.

## Publicação

Publique os arquivos em uma hospedagem estática com HTTPS.
Depois, abra o endereço publicado no celular.

## Observação

As calorias são estimativas gerais e não substituem
orientação médica ou de um profissional de educação física.
